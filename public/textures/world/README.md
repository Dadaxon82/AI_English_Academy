# 3D olam teksturalari

Barcha fayllar **Poly Haven** (https://polyhaven.com) teksturalaridan olingan — litsenziya **CC0 1.0** (jamoat mulki,
mualliflikni ko'rsatish shart emas; hurmat yuzasidan ko'rsatilgan). Asl 1k JPG fayllar WebP'ga o'girilgan, kichraytirilgan
va rang xaritasi (`*_diff`) sahna uslubiga moslab bo'yalgan (yorqinlik detali saqlangan). `*_nor` — normal (OpenGL),
`*_rough` — g'adir-budurlik.
